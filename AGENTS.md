# Repository instructions

- Keep every public document, commit, and pull request in English.
- Never add credentials, tokens, personal data, production secrets, private URLs, or machine paths.
- Preserve Keycloak as the identity source of truth; business stores receive credential-free projections.
- Treat role, resource, scope, event, migration, and theme changes as reviewed contracts.
- Add evidence for success, refusal, idempotency, retry, privacy, and compatibility where applicable.
- Do not claim production readiness from a local build.
- Do not commit, push, merge, publish, or add AI attribution without the repository owner's explicit word.
