# Code of conduct

We are committed to a respectful, inclusive, and harassment-free community. Discuss ideas and code with
empathy and precision, keep disagreement focused on evidence, and respect privacy, licensing, and
responsible disclosure.

Harassment, discrimination, threats, doxxing, sexualized attention, intimidation, personal attacks, or
publishing another person's private information are not acceptable. Maintainers may edit or remove
contributions and restrict participation when behavior is unsafe or disruptive.

This policy applies to issues, pull requests, reviews, discussions, and public spaces where a person
represents the project. Report conduct concerns privately through the repository owner's GitHub profile.
Security vulnerabilities use [SECURITY.md](SECURITY.md).
